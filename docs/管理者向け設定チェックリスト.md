# 管理者向け 設定チェックリスト

運用前と、定期的（月1回目安）に確認する項目です。
※ Cloudflare の画面の名称や場所は変更されることがあります。**画面の表記が違うときは、Cloudflare のドキュメントで最新の手順を確認してください**（ここに書いた画面名は作成時点の目安で、確実ではありません）。

## A. アカウントの安全（運用開始前に必須）

- [ ] **Cloudflare アカウントの2段階認証（2FA）が有効**になっている
  - 目安: ダッシュボード右上のプロフィール →「Profile」→ Authentication（2段階認証）
  - 管理者が複数人いる場合は、全員が有効にする
- [ ] Cloudflare Access（Zero Trust）の許可リストに、**今の利用者だけ**が入っている（退職者・異動者を削除）
- [ ] アプリ側のユーザー管理（管理画面）も、今の利用者と権限（閲覧のみ／入力可／管理者）が合っている
- [ ] `workers.dev` の公開URLや、R2 の公開URL（`r2.dev`）を**有効にしていない**

## B. 使用量アラート（課金を防ぐ）

無料枠を超えると、止まらずに**自動で課金**されます。通知を設定しておくと気づけます。

- [ ] ダッシュボードの **Notifications（通知）** で、使用量・請求に関する通知を作成し、**届くメールアドレスを確認**する
  - 通知の種類の名前はプランや時期によって異なる場合があります（不確か）。使用量・請求に関するものがあれば有効にしてください
- [ ] 管理画面の「ファイル容量」タブで、無料枠の使用状況を月1回確認する
  - 詳しい数字（リクエスト・D1の行数・R2の操作回数など）を見るには、環境変数 `CF_API_TOKEN`（読み取り専用）と `CF_ACCOUNT_ID` を設定します。設定しない場合は、各項目の無料枠とダッシュボードへの案内だけが出ます
- [ ] R2 の容量: 8GBで警告、9GBでアップロード拒否になります。動画を大量に保存する運用なら、不要なファイルを「ファイル容量」タブから**物理削除**して空けます

| サービス | 無料枠（目安） |
|---|---|
| Workers / Pages Functions | 10万リクエスト/日 |
| D1 | 5GB・読取500万行/日・書込10万行/日 |
| R2 | 10GB・Class A 100万回/月・Class B 1000万回/月 |
| Access | ユーザー50名まで |
| Pages ビルド | 500回/月 |

## C. 環境変数（Pages の設定 → 環境変数。本番・プレビュー両方）

- [ ] `ACCESS_TEAM_DOMAIN` / `ACCESS_AUD`: Access の署名付きトークンの検証を有効にする（プレビューURLでのなりすまし防止）
- [ ] （任意）`VAPID_PUBLIC_KEY` / `VAPID_PRIVATE_KEY`: プッシュ通知を使う場合
- [ ] （任意）`AI_VISION_ENABLED=1`: 計器の写真読み取り・銘板の自動読み取りを使う場合（Cloudflare 側でモデルのライセンス同意が必要。未同意だとエラーになるため、既定は非表示）
- [ ] （任意）`R2_WARN_BYTES` / `R2_HARD_LIMIT_BYTES`: R2 容量の警告・上限を変える場合

## D. バックアップ・復旧

- [ ] 管理画面「バックアップ」から、**SQLダンプ**（または JSON）を月1回ダウンロードして、別の場所に保管する
- [ ] 万一の手順を把握している（詳細は README）
  1. アプリが壊れた → Cloudflare Pages の「Deployments」から**直前のデプロイにロールバック**
  2. データを誤って消した・書き換えた → **D1 Time Travel**で過去30日の時点に復元
  3. マスタ設定を誤った → 管理画面の「マスタ変更履歴」から旧バージョンに戻す
  4. 個別のデータを削除してしまった → 管理画面の「削除済みデータ」から復元
- [ ] 写真・動画（R2）はバックアップに**含まれません**。重要なファイルは別途保管してください

## E. 定期確認（月1回）

- [ ] 管理画面の「監査ログ」で、見覚えのない操作がないか
- [ ] 通知のベルに未確認の期限超過が溜まっていないか
- [ ] 年度の切り替え（10月）: 年間計画の**年度リセット**を実施（前年度の未実施を確認してから）
