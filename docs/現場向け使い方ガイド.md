# 設備保全アプリ 現場向け使い方ガイド

スマホで開いたまま、現場で読める短い手順集です。画面の名前はアプリのとおりに書いています。
（管理者向けの設定は `管理者向け設定チェックリスト.md` を見てください）

## 0. はじめに

- **ホーム画面に追加**すると、アプリのように使えます。
  - iPhone: Safari で開く →「共有」→「ホーム画面に追加」
  - PC: Edge / Chrome のアドレス欄の「インストール」
- ログインは会社メールに届く**ワンタイムコード**を入力します（パスワードは不要）。
- **文字を打つのが面倒なとき**：iPhone のキーボードにあるマイク🎤を押すと、話した言葉をそのまま入力できます（現象・原因・対策・日報・チャットなど）。マイクが出ないときは、iPhone の「設定」→「一般」→「キーボード」で「音声入力」をオンにしてください。周りがうるさい現場では、誤変換がないか読み返してから保存してください。
- 権限は3段階です。**閲覧のみ**（見るだけ）／**入力可**（記録・更新ができる）／**管理者**（設定・削除済みの復元など）。
- 誰が・いつ・何をしたかは自動で記録されます。削除しても履歴は残ります。

## 1. 電波が悪い・ない場所で使うとき

- 入庫・出庫、点検などは、電波が無いと**「送信待ち」**に保存され、電波が戻ると自動で送られます。
- 画面の下に「📤 送信待ち」のバーが出ているときは、まだ送られていない記録があります。
- 送れなかった記録がある場合は、バーの**「失敗を確認」**を押すと理由（例: 在庫不足）が見えます。1件ずつ**「再送」**か**「破棄」**を選べます。在庫不足の出庫は、在庫を勝手に変えないため失敗のまま残ります。
- 棚卸（在庫の実数を入れる操作）は、後から送ると間の出庫を消してしまうため、**電波があるときだけ**できます。
- 「🔑 再ログインする」と出たときは、それを押して会社メールで入り直してください。

## 2. 部品在庫（QRで、その場で出庫・入庫）

1. 部品に貼った**部品QR**を、一覧の「📷 部品QR」またはスマホのカメラで読み取ります。
2. 部品のページの上の**「その場で記録」**で、数量を＋/−で合わせて「出庫」か「入庫」を1回押します。
   - 2回タップしても二重には反映されません。
   - 電波が無い倉庫でも記録できます（送信待ちになります）。この端末で前に見たことがある部品なら、名前と在庫の目安も出ます。
3. 在庫が必要数を下回ると発注アラートが出ます。「発注」ボタンで発注メールの下書きができ、発注中バッジが付きます。入庫すると自動で消えます。
4. 部品一覧・詳細は、開いている間20秒ごとに自動で最新になります（他の人の入出庫が反映されます）。
5. **棚卸**: 一覧の「📋 棚卸」で実数を入力 →「差異N件を一括確定」。数量は 1,000,000 までです。

### 部品QRのラベルを印刷する
- 部品一覧の「🏷 部品ラベル印刷」（部品のページなら「🏷 ラベルを印刷」）→ 台紙は **A4・40×40mm・24面**です。
- **使いかけの台紙**は、台紙のミニ図で「上から◯段目・左から◯列目」をタップすると、そこから印刷できます（印刷ダイアログは「A4／倍率100%／余白なし」）。
- **ラベル印刷は必ず本番のURLで**行ってください（試験用URLで印刷したQRは後で開けません）。

## 3. 設備台帳・QR

- 設備に貼ったQRを「QR」ボタンで読み取ると、その設備のページに飛べます。
- 設備のページから、**トラブル記録**や**業務依頼**をその設備を選んだ状態でワンタップで作れます。
- 設備が多い場合、一覧は先頭から表示されます。「先頭N件のみ」と出たときは、検索で絞ってください。
- 設備のページの**「全履歴（時系列）」**で、その設備の点検・トラブル・業務依頼・保全計画・使用部品（業務依頼やトラブルに紐づけた入出庫）を、新しい順に1本で見られます。上の「点検」「トラブル」などのボタンで絞り込み、「もっと見る」で古いものまでたどれます。「前回いつ何をしたか」を調べるときに使ってください。

## 4. 点検実施

- チェックリストに OK/NG・数値・選択で入力します。上限・下限を外れた数値は、その場で警告が出ます。
- 数値の下に、**前回の値と今回との差**（↑↓→）が出ます。基準内でも悪くなっている兆候に気づけます。
- 写真・動画を付けて記録できます（写真は自動で小さくなり、位置情報は消えます）。
- 予定（保全計画）から点検を開くと、保存したときに**予定が完了**になります。

## 5. 保全計画（カレンダー・年間計画表）

- 点検・部品交換・工事・その他の予定をカレンダーで共有します。完了・未実施・期限超過は色で分かります。
- 複数日の予定は、日付をタップして**その日だけ**削除・完了にできます。予定全体の削除・完了は、計画の詳細から行います。
- **年間計画表**は10月〜翌9月の会計年度で表示します。過去の年度は、リセット時に保存されたCSVで確認します。
- **年度リセット（管理者のみ）**: 新しい年度の最初（10月以降）に、完了状態を未実施に戻します。押す前に、前年度の未実施が残っていないか確認してください。
- 工事予定は、**3日前までに工事連絡書を印刷していない**と通知が出ます（帳票出力で印刷日が記録されます）。
- 工事連絡書の「担当」と「工事概要」は、空欄なら計画の「担当者」と「備考」（備考が空ならタイトル）で自動的に補われます。会社名・連絡先・責任者・安全チェックは、計画の編集ページで入れてください。

## 6. トラブル記録

- 写真・動画つきで、ジャンル・現象・原因・対策を記録します。
- 現象を入力すると、**過去の似たトラブル**が最大5件出ます。原因・対策の参考にしてください。
- 「🤖 AIに原因・対策のヒントをもらう」を押すと、AI が案を出します（押したときだけ動きます。入力可以上。AIが使えない設定のときはボタンが出ません）。AIの案は**参考**です。必ず現場で確認してください。
- 一覧は、条件を選んで「🔍検索」を押すと出ます。
- 編集ページの「トラブル報告書（帳票）の入力」に入れておくと、「帳票出力」で会社のExcel用紙に自動で差し込まれます。
  - **空欄の欄は、すでに入力した内容で自動的に補われます**：調査対象←設備、トラブル名←現象、処置←対策、担当者印←記録者の苗字。入力した値があればそちらが優先されます。
  - 手で入れるのは、整理NO・休止時間・休止区分・有効性の確認・特記事項だけです。

## 7. 業務依頼

- 「これ直して」などの依頼を登録し、**受付 → 対応中 → 部品待ち → 完了**で進み具合を見える化します。
- 優先度（高/中/低）と対応期限を付けられます。期限を過ぎて未完了のものは「⚠期限超過」と出ます。

## 8. 日報・ユーティリティ日報

- **日報**: 日付・記録者・カテゴリで記録・閲覧します（提出や承認はありません）。トラブルなどの画面から「日報に記録」で内容を引き継げます。
- **ユーティリティ日報**: 灯油・ボイラー・空気圧縮機・タンク・蒸気ボイラー・ドレンなどの日常点検を、**1日1件**記録します。
  - 数値は半角・全角どちらでも入ります。前回の値と、基準を外れたときの警告が出ます。
  - 同じ日のものが既にあると、新規ではなく**既存の記録の編集**に進みます。
  - 一覧から期間を指定して CSV を出力できます。

## 9. 電気設備点検

- 高圧受電設備・蓄電池・発電機の日常点検を記録します（専用の画面です）。
- **電波が無くても保存・削除できます。** 電波が無いと、記録はこの端末の「送信待ち」に保存され（画面下に「📤 送信待ち」と出ます）、電波が戻ると自動でサーバーに送られます。保存中にもう一度押しても二重には登録されません。
- 送信できなかった記録は、バーの**「内容を確認」**で理由を見て、1件ずつ「再送」か「破棄」を選べます。
- **写真は電波のある場所でしか送れません。** 写真を付けたまま電波の無い場所で保存しようとすると断られます。写真を外して保存するか、電波のある場所で保存してください。
- 同じ記録を別の端末が先に直していても、後から送られた方が上書きします（上書き前の内容は監査ログに残ります）。同じ日・同じ設備を複数人で入力しないようにしてください。
- 設定（点検項目）の変更は管理者のみです。

## 10. 検索とAIサポート

- **横断検索**: キーワード（例「コンプレッサ 異音」）で、過去のトラブル・点検・依頼・日報・設備・部品・計画をまとめて探せます。全角半角やひらがな・カタカナの違いは吸収されます。結果は CSV で出力できます。
- **AIサポート**: 設備が止まったときに、1行入力するだけで「過去の似たトラブル」「関連する部品の在庫」「関連する業務依頼」が出ます。「🤖 対応策の案をもらう」を押したときだけ AI が案を出します。

## 11. チャット（引き継ぎ）

- シフト間の引き継ぎに使います。メッセージは**送信から10日で自動削除**されます。残したいものは📌ピン留め、または📋で**トラブル記録・業務依頼・日報**にして残してください。
- 「👍」は「了解した」の表明です（既読とは別です）。
- **氏名・電話番号・住所などの個人情報は書かないでください**（書こうとすると警告が出ます）。

## 12. 通知

- ホームのベル🔔に、在庫切れ・発注アラート・点検の異常・トラブル登録・期限超過などが出ます。誰か1人が確認すると全員の未読が減ります。
- 「🔔 プッシュ通知を有効にする」を押すと、アプリを開いていなくても通知が届きます（設定されている場合のみ）。

## 13. 守ってほしいこと

- 写真に**人の顔・社外秘の書類**が写り込まないようにしてください。
- 入力欄に個人情報を入れないでください。
- アプリが動かなくなったら管理者へ連絡してください（前のバージョンにすぐ戻せます）。

## 14. 困ったとき

| 症状 | 対処 |
|---|---|
| 「🔑 再ログインする」と出た | それを押して、会社メールで入り直す |
| 画面が古いまま・新機能が出ない | アプリを一度閉じて開き直す（それでも変わらなければ管理者へ） |
| 「送信待ち」が消えない | バーの「失敗を確認」で理由を見て、再送か破棄 |
| 在庫が合わない | 部品の「入出庫履歴」を確認。合わなければ棚卸で合わせる |
| 誤って削除した | 管理者に連絡（管理画面の「削除済み」から復元できます） |
