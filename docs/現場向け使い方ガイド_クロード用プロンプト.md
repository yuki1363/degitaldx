# 現場向け「使い方ガイド」を Claude（claude.ai）で作るための貼り付け用プロンプト

## 使い方（手順）
1. ブラウザで **claude.ai** を開く（無料アカウントでOK）。
2. 下の「===ここから貼り付け===」〜「===ここまで===」の**全文をコピー**して、claude.ai のメッセージ欄に貼り付けて送信。
3. Claude が右側に「Artifact（成果物）」として、見やすい使い方ガイドのWebページを作ります。
4. 気になる所は「もっと写真を大きく」「文字を大きく」「この機能を詳しく」などと**追加で頼めば修正**してくれます。
5. 仕上がったら、Artifact 右上の共有/コピーから配布、またはブラウザの「印刷→PDFで保存」で配れます。

> ヒント: スクリーンショット（点検画面・トラブル画面など）を一緒に貼り付けると、その画像を使った、より分かりやすいガイドになります。

===ここから貼り付け===

あなたはUI/UXデザイナーです。工場の保全担当者（現場の作業者）向けに、社内Webアプリ「設備保全オールインワンアプリ」の**使い方ガイド**を、1ページのインタラクティブなHTML（Artifact）として作ってください。

【目的・読む人】
- 読む人: 工場の現場メンバー（点検・修理・部品管理をする人。ITは得意でない人も含む）。
- 目的: このアプリで「何ができて」「どう使えばいいか」が、見ただけで分かること。

【デザイン要望】
- 日本語。専門用語は避け、やさしい言葉で。
- スマホでも見やすい（現場はスマホ中心）。大きめの文字、たっぷりの余白、アイコン多め。
- 機能ごとにカード/セクションで区切り、色分け。手順は「1→2→3」のステップで。
- 親しみやすく、でも業務用らしく落ち着いた配色。
- 各機能に「アイコン＋機能名＋ひとことの説明＋使う手順」を入れる。
- 最初に「このアプリでできること」のサマリー、最後に「困ったとき」と「注意」を入れる。

【アプリの概要】
- 工場の設備保全（点検・修理・在庫・報告）を、現場のスマホ/PCだけで完結できるアプリ。
- 紙やバラバラの管理をやめ、「点検〜修理〜在庫〜報告」を一つにまとめる。
- スマホの「ホーム画面に追加」でアプリのように使える（PWA）。会社メールでログイン。

【使う前の準備】
- iPhone: Safariで開く →「共有」→「ホーム画面に追加」。
- PC: Edge/Chromeのアドレス欄の「インストール」。
- ログインは会社メールに届くワンタイムコードを入力（パスワード不要）。

【機能ごとの使い方（この内容を分かりやすく整理してガイドにしてください）】

1. ホーム（通知）
   - 開くと、今やるべきこと（期限超過の予定・もうすぐ期限・新着のトラブル/点検/在庫アラート・チャットの未読）がタブでまとまって出る。
   - 通知は「確認」を押すと全員ぶん既読になる（チーム共有）。

2. 設備台帳
   - 設備の情報・図面・点検/修理/トラブルの履歴を一か所で確認。
   - 設備に貼ったQRコードを「QR」ボタンで読み取ると、その設備のページにすぐ飛べる。

3. 点検実施
   - チェックリストで点検結果を入力（OK/NG・数値・選択）。スマホで簡単。
   - 上限・下限を外れた数値は、その場で警告が出る（異常値アラート）。
   - 写真・動画を付けて記録。複数設備をまとめて入力することも可能。

4. 保全計画（カレンダー・年間計画表）
   - 点検・部品交換・工事などの予定をカレンダー/年間表で管理。
   - 終わったら「完了」にチェック。未実施・完了でしぼり込みもできる。

5. トラブル記録
   - 設備の不具合を、写真・動画付きで記録（ジャンル・現象・原因・対策）。
   - 編集ページの「トラブル報告書（帳票）の入力」欄に休止時間・処置・担当者などを入れておくと、
     「帳票出力」で会社のExcel報告書に自動で差し込める（担当者は赤丸ハンコも自動生成）。

6. 業務依頼
   - 「これ直して」などの依頼を登録し、受付→対応中→部品待ち→完了 で進み具合を見える化。
   - 「言った・言わない」を無くす。写真添付・設備との紐づけも可能。

7. 部品在庫
   - 使った部品は +/− ボタンで在庫をその場で更新。
   - 必要数を下回ると発注アラート。「発注」ボタンで発注メールの下書きを自動作成。

8. 日報
   - その日の作業・引き継ぎを記録。カテゴリや日付・記録者でしぼり込んで閲覧。
   - トラブルや点検の画面から「日報に記録」で内容を引き継いで書ける。

9. 横断検索
   - キーワード（例「コンプレッサ 異音」）で、過去のトラブル・点検・依頼・日報・設備を一気に検索。

10. チャット / コメント
    - シフト間の引き継ぎや、各記録へのコメント。
    - ※ 氏名・電話番号など個人情報は書かないこと（書こうとすると警告が出る）。

【注意・お願い（ガイドの最後に入れてください）】
- 写真に人の顔・社外秘の書類が写り込まないように。
- チャットや入力欄に個人情報（氏名・電話・住所など）は入れない。
- 操作した人・日時は自動で記録される。削除しても履歴は残るので安心。
- 動かなくなったら管理者へ連絡（前のバージョンにすぐ戻せる）。

以上をもとに、現場の人が「これ見れば使える」と思える、明るく分かりやすい使い方ガイドのHTML（Artifact）を作ってください。

## 補足: もっと良くするコツ
- 実際の画面の**スクリーンショット**を claude.ai に貼ると、その画像入りガイドになります。
- 「ポスター1枚にして」「3つ折りパンフ風に」「動画マニュアルの台本にして」なども頼めます。
- 機能を追加/変更したら、この `.md` の該当箇所を直して貼り直せば、ガイドも最新になります。
