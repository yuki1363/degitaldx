# 実機確認チェックリスト

開発環境（自動テスト）では確認できない項目を、**実際の端末・本番環境**で確認するための表です。
新しい版を公開したあと、または運用開始前に一度通して行ってください。結果は表の「結果」欄に ○ / × / 日付で書き込みます（コピーして使ってください）。

- 確認した日: ____ 　確認した人: ____ 　アプリの版（`sw.js` の `CACHE_VERSION`）: ____
- ✗ が出たら、その項目・端末・画面の写真を添えて開発者に連絡してください。
- ここに書いた「自動テストで確認済み」は、**ブラウザ上の模擬環境**での確認です。実機・本番では動きが違う場合があります。

## 3. 電波が悪い・ない場所

端末を機内モードにして確認します。確認後は必ず機内モードを解除してください。

| # | 確認すること | 期待する結果 | 結果 |
|---|---|---|---|
| 3-1 | 一度開いた部品のページを、機内モードで開く | 「オフラインのため…」と、最後に見た名前・在庫の目安が出る | |
| 3-2 | 機内モードで「その場で記録」→ 出庫 1 を押す | 「送信待ちに保存しました」と出て、画面下に「📤 送信待ち」が出る | |
| 3-3 | 続けて同じ操作を2回、数量を変えて1回行う | 押せなくならず、3件が送信待ちに積まれる | |
| 3-4 | 機内モードを解除する | 数十秒以内に自動で送られ、「📤 送信待ち」が消える。在庫は合計ぶんだけ減る（二重に減らない） | |
| 3-5 | 在庫より多い数の出庫を機内モードで記録し、解除する | 送信は失敗し、バーに「うち失敗」が出る。「失敗を確認」で理由（在庫不足）が見え、破棄できる。在庫は変わらない | |
| 3-6 | 機内モードで電気設備点検を入力して「保存する」 | 「この端末に保存しました」と出て、画面下に「送信待ち」が出る | |
| 3-7 | 機内モードを解除する | 自動で送られ、バーが消える。管理画面で記録が確認できる | |
| 3-8 | 機内モードで電気設備点検の記録を「削除」→ 解除 | 解除後にサーバーでも削除される | |
| 3-9 | 機内モードで、**写真を付けたまま**電気設備点検を保存する | 「写真は電波のある場所でしか送れません」と案内される | |
| 3-10 | 機内モードでホームを開く | アプリは起動する（データは古い表示になる） | |
